# スナックイキタイ共有プレビュー

トップ画面と全国マップの共有用試作。本番サイトとは別です。

全国マップは2026-10-29から公開APIの最新店舗データに接続しています。画面表示中は1分ごとに更新を確認し、店舗・公開写真・有料区分・イキタイ／スナ活集計の変更を反映します。通常検索・店舗詳細は https://snack-ikitai.com/ に移動します。

写真あり → 有料 → イキタイ数 → スナ活数の順に優先します。提携区分を有料として扱いません。公開対象外の店舗・写真は除外し、更新確認に失敗した場合はエラーと再読み込みを表示します。

更新対象は管理画面・DBに保存された情報です。外部サイトの自動収集や決済判定は行いません。APIの無料サーバー停止後は初回の起動待ちが発生する場合があります。旧ビルド用の静的dataファイルは現在のmap.htmlでは参照しません。
